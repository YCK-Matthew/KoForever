# KoForever

와우 포에버(한국어 클라이언트) 애드온 중 한국어가 없는 부분을 한글로 바꿔 주는 **비공식 무료** 패치 프로그램입니다.

## 내려받기

오른쪽 [Releases](../../releases/latest)에서 가장 최근 `KoForever_v버전.zip`을 내려받아 압축을 풀고 `KoForever.exe`를 실행하세요.
v4.5부터는 앱을 켜면 새 버전이 있는지 알려 주고, [내려받기]를 누르면 내려받기 폴더에 저장합니다.

## 알아 두기

- 블리자드·애드온 제작자와 무관한 비공식 패치입니다. 애드온 원본 파일은 고치지 않으며 언제든 [원래대로] 되돌릴 수 있습니다.
- 회사 서명이 없는 개인 제작 앱이라 윈도우 파란 경고창이 뜨면 [추가 정보] → [실행]을 누르세요.
- 무료 배포 전용이며 판매를 금지합니다. RestedXP 가이드 번역은 원작 라이선스(CC BY-NC-SA 4.0)를 따르고, 게임 속 한국어 이름의 저작권은 Blizzard Entertainment에 있습니다.
