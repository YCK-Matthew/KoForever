# KoForever

와우 포에버(한국어 클라이언트)에서 영어로만 나오는 애드온 문구를 한국어로 바꿔 주는 **비공식 무료** 패치 프로그램입니다.
아이템·기술·지역·NPC 이름은 게임에 실제로 쓰이는 공식 한국어 이름을 따르고, 공식 이름이 없는 것은 추측하지 않고 영어로 둡니다.

## 한글로 바꾸는 애드온

| 분류 | 애드온 | 바뀌는 곳 |
|---|---|---|
| 레벨업·퀘스트 | RestedXP 가이드 | 레벨업 동선 안내 문장과 설정 창 |
| | Questie | 지도의 퀘스트·NPC·사물·아이템 이름, 메뉴와 안내 |
| | Attune | 입장 퀘스트 이름과 목표(공식 한국어) |
| 장비·던전 | GearQuest Forever | 장비 업그레이드 목록과 얻는 방법 설명 |
| | ForeverDungeonJournal | 던전 퀘스트, 우두머리, 공략 메모 |
| | AtlasLoot | 포에버 던전·우두머리 이름, 명예 계산기, 즐겨찾기 공유 안내 |
| 전투·이름표 | Details! | 본체 설정 창과 플러그인 7종 |
| | Plater | 이름표 설정 창 |
| | Decursive | 약화 효과 해제 도우미 설정 창 |
| | RareScanner | 희귀 몹 알림 설정 창 |
| 편의·채팅 | What's Training, TomTom, Baganator, Posty, Prat, MinimapButtonButton, SpeedyAutoLoot, Leatrix Plus·Maps, Auctionator, RangeDisplay | 설정 창, 안내, 원작 한국어에 빠진 칸 |

내 와우에 설치된 애드온에만 적용됩니다. 게임 언어가 한국어일 때만 한글로 보입니다.

## 처음 받기

1. 오른쪽 [Releases](../../releases/latest)에서 가장 최근 `KoForever_v버전.zip`을 내려받습니다.
2. 압축을 풀고 `KoForever.exe`를 **문서 폴더나 바탕화면처럼 내 폴더**에 둡니다.
   `Program Files`처럼 쓰기 권한이 없는 폴더에 두면 앱이 스스로 업데이트하지 못합니다.
3. `KoForever.exe`를 실행합니다. 처음 켜면 "처음 설정" 창이 와우 폴더 확인, 모두 한글로, 자동 다시 적용 켜기를 차례로 안내합니다.

직접 받는 것은 처음 한 번뿐입니다. 그 뒤로는 앱이 스스로 업데이트합니다.

## 사용 방법

- **[애드온]** 화면에서 [모두 적용]을 누르면 내 와우에 있는 애드온 전부에 한글 패치를 입힙니다. 하나씩 고르면 바뀌는 곳과 번역 전·후를 볼 수 있습니다.
- 게임이 켜져 있다면 채팅창에 `/reload`를 입력하면 바로 바뀝니다.
- 언제든 **[원래대로]** 를 누르면 패치 전 상태로 돌아갑니다. 애드온 원본 파일은 고치지 않습니다.

### 애드온이 업데이트되면

CurseForge 등으로 애드온이 업데이트되면 한글 패치가 풀립니다.
**자동 다시 적용** 스위치를 켜 두면 윈도우 예약 작업이 30분마다 확인해, 패치가 풀린 애드온만 다시 입힙니다(관리자 권한 필요 없음).
켜 두지 않았다면 앱을 열었을 때 노란 줄에 표시되는 [다시 적용]을 누르세요.

### 설정 보관

[설정 보관] 화면에서 와우 설정(WTF 폴더)을 압축해 보관하고, 다른 PC에서 불러올 수 있습니다.
불러오기 전에는 지금 설정을 먼저 백업합니다.

## 업데이트

앱을 켤 때 새 버전이 있으면 알려 줍니다. **[바로 업데이트]** 를 누르면 새 버전을 받아 지금 쓰는 앱과 바꾸고 다시 켭니다.
받은 파일이 여기 올린 원본과 같은지 지문(SHA-256, 파일 내용이 한 글자라도 다르면 달라지는 고유 값)으로 확인한 뒤에만 바꿉니다.
같은 자리에 같은 이름으로 바뀌므로 자동 다시 적용도 그대로 이어집니다.

v4.16 이하를 쓰고 있다면 바로 업데이트 기능이 없으니, 위 "처음 받기"대로 한 번만 직접 받아 바꿔 주세요.
버전별로 바뀐 내용은 앱의 [새 소식] 화면과 각 릴리스 설명에 있습니다.

## 알아 두기

- 블리자드와 애드온 제작자들과는 관계없는 비공식 패치입니다.
